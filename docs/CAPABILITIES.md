# 能力生命周期

已确定：默认完整协助，生成包时声明范围，agent 在范围内自主部署，无逐项确认窗口；工具内置优先，允许添加有来源、校验及清理信息的可信工具。

本轮实现内置截图的生命周期原型和外部工具来源登记。截图调度及清理通过隔离的任务替身测试，实际桌面后端、SYSTEM/交互用户 ACL 和原生任务回收尚待 VM 验收。外部登记只保存信息，不自动下载或安装。

## 建议流程

1. agent 请求某项能力，例如截图或桌面输入。
2. 管理器检查本次声明范围、有效期、目标环境及已有资源。
3. 已有可用实例就复用；缺失时安装到会话专属目录，记录版本、来源、文件、进程及任务。
4. 在真实验证成功后返回可用接口。仅完成安装时，状态为“已安装，未验证”。
5. 短暂断线保留实例；重连先检查并复用，执行结果未知的操作不自动重放。
6. 明确停止或授权到期后，停止本次实例、撤销接口并清理本次拥有的临时资源。

## 哪些东西会清理

| 对象 | 建议默认处理 |
|---|---|
| 本次创建的桌面代理、监听口、计划任务、访问凭据 | 停止、撤销并清理 |
| 本次生成的临时控制脚本与临时文件 | 清理；用户修改或归属无法确认时保留并报告 |
| 诊断日志、报告与隔离记录 | 默认保留，隐藏凭据；说明保存位置及如何删除 |
| 用户原有的软件、服务、配置 | 保留；具体维修任务另行记录所需变更 |
| 作为修复成果安装的软件，例如杀毒软件 | 保留，并在完成记录中说明 |

清理只依据本次资源记录，不按软件名称批量卸载，也不删除未知归属文件。安装或部署前先记录计划；完成后读回实际资源，避免中途失败导致漏记。

## 资源记录

每个实例保存 sessionId、capabilityId、版本、来源、授权范围、创建时间、状态、验证结果及本次创建的资源。进程记录 PID 与启动时间，文件记录路径与哈希，计划任务使用会话专属名称。协助前已有资源记为复用，不取得删除所有权。

能力状态分别为：未安装、部署中、已安装未验证、可用、断线待检查、停止中、已清理、清理未完成。无法确认时报告未知，保留重试或人工处理路径。

## 第一个能力

第一项能力是目标登录用户桌面截图；鼠标键盘后续实现。截图在交互用户的限权一次性任务中执行，不开启额外网络监听。使用随机请求编号确认新结果，下载时核对 SHA-256。`ensure` 会实际请求一次截图验证，`inspect` 返回历史记录；任务还在执行时拒绝重放。

资源放在目标会话的 `capability-state/screenshot`，原始模板在 `capabilities/screenshot`，两者分离。记录 task 名称、动作、用户 SID、文件哈希及可获取的子进程 PID/启动时间；配置变化、文件变化和 PID 复用会拒绝执行或删除。清理保留截图和诊断记录，删除未改动的临时脚本、请求与 lease，并取消自有任务。

当前需要管理员 SSH 账户管理任务，截图进程以登录用户身份运行；无登录用户、已到期或范围不含截图时拒绝。后端检查输入桌面，锁屏/UAC 安全桌面不支持。多登录用户和仅 RDP 登录场景尚待验证，暂通过 Win32_ComputerSystem 的 UserName 选择桌面。

控制接口提供 `ensure`、`inspect`、`capture`、`stop`、`cleanup`。CLI 与 MCP 共用实现；agent 自行决定何时请求能力，管理器记录部署事实与生命周期。接口约定见 [INTERFACES.md](INTERFACES.md)。

## 工具来源

内置优先。外部工具登记需要固定版本、HTTPS 来源、预期 SHA-256、审核者及审核依据、能力范围和清理步骤；不接受超出声明范围、无依据或含来源凭据的描述。相同 ID 的版本和来源不允许静默替换。

登记表示“来源和审核信息已记录”，不会被标成已安装或验证成功。hash 需在后续下载时核对，来源可信性需实际审核；填写字符串不能自动证明工具安全。当前尚无外部部署适配器，agent 的手工部署仍须记录本次资源，遵守已授权范围及清理约定。

管理员 SSH 当前拥有广泛执行权限，清单或范围检查只约束管理器入口；不声称已经阻止通过普通命令绕过。系统级隔离单独设计。
